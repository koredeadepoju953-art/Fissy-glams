# Tissy Glams Studio

A multi-page website for Tissy Glams Studio, a makeup, gele and beauty products studio in Abeokuta, Nigeria.

## Features
- Book makeup and gele sessions, with an estimated total and deposit
- Shop beauty products with category filters, search and shade options
- Cart and checkout with pickup or delivery, with a fee by area
- Makeup and gele training classes with an enquiry form
- Bookings, orders and enquiries are sent to the studio on WhatsApp

## Pages
Home, Services, Book, Shop, Cart, Training, Contact

## Tech
HTML, CSS and vanilla JavaScript. No build step or backend. Deploys as a static site on Vercel.

## Editing content
Studio details, prices, products, delivery fees and classes are all in `js/data.js`. Product photos go in the `images/` folder.
